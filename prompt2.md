with profile cards.

# 25. ROLE-AWARE UI

The UI should dynamically reflect permissions.

Do not merely hide everything based on a simple role name.

The backend determines authorization.

The frontend uses the effective permissions to determine:

- Navigation
- Actions
- Buttons
- Menus
- Data visibility
- Edit controls
- Approval controls

Example:

An instructor may see:

    Create Question

but not:

    Manage Permissions

A Branch Manager may see:

    Branch Students
    Branch Classes
    Branch Reports

but not:

    Global Organization Settings
